# 💎 Smart Finance Tracker

## About Project

Smart Finance Tracker is a cloud based expense management system.

## Features

• Add Income and Expense
• Track Balance
• Category wise analysis
• Monthly budget tracking
• Transaction history
• Graph based reports

## Technologies Used

• HTML
• CSS
• JavaScript
• Firebase (Future Integration)

## How to Run

1. Download the project
2. Open index.html
3. Run using Live Server
